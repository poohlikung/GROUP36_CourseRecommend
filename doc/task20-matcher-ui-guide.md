# Task 20 — แบบทดสอบและผลแนะนำคอร์ส

หน้า `/match` เปิดให้ทุกคนใช้ได้โดยไม่ต้องล็อกอิน เข้าจากเมนูหรือปุ่มบนหน้าแรก ผู้ใช้ตอบคำถาม 4 ช่วง: หมวดหมู่ ระดับกับภาษา งบประมาณ และเวลาเรียนต่อสัปดาห์ จากนั้นหน้าเว็บขอ CSRF token และส่งคำตอบไปยัง `POST /api/v1/course-matches` ตาม [สัญญา API ของ Task 19](task19-matcher-guide.md)

หน้าเว็บตรวจงบ 0–99,999,999.99 บาท ทศนิยมไม่เกิน 2 ตำแหน่ง และเวลา 1–168 ชั่วโมงเป็นจำนวนเต็มก่อนส่ง API ผลลัพธ์แสดงสูงสุด 3 คอร์ส พร้อมคะแนน เหตุผล ราคา และลิงก์คอร์ส หากไม่พบคอร์ส จะแสดงข้อจำกัดที่ API ส่งกลับและให้แก้คำตอบได้โดยไม่ทิ้งค่าที่เลือกไว้ ระบบไม่ผ่อนเงื่อนไขให้เอง

ทดสอบที่ `test/frontend/matcher-flow.test.tsx` ครอบคลุมการตอบครบ 4 ช่วง การส่ง JSON พร้อม cookie/CSRF การแสดงเหตุผลของคอร์ส การกันเวลาไม่ถูกต้อง และกรณีไม่พบคอร์ส พร้อมทดสอบ frontend ทั้งชุดและ production build งานนี้ยังไม่ได้ทดสอบ browser E2E กับ backend ที่รันจริง จึงไม่ใช้ผล mock เป็นหลักฐานว่าการ deploy เชื่อมต่อสำเร็จ
