## ลองผ่าน browser กับระบบจริง

สร้าง backend จากโค้ดปัจจุบันด้วย Docker และใช้ PostgreSQL 16 แยกจาก container เดิม จากนั้นเปิด frontend ผ่าน Vite ที่ proxy `/api` ไปยัง backend ชุดทดสอบนี้ ผู้ใช้ไม่ได้ล็อกอิน

| กรณี | คำตอบที่ใช้ | ผลที่เห็น |
| --- | --- | --- |
| พบคอร์ส | `programming`, `BEGINNER`, `ENGLISH`, งบ 0 บาท, 4 ชั่วโมง/สัปดาห์ | ได้ `Introduction to Computer Science (CS50x)` คะแนน 71.11/100 พร้อมเหตุผลด้านราคา เวลา และรีวิว; ลิงก์คอร์สแสดงถูกต้อง |
| ไม่พบคอร์ส | เปลี่ยนหมวดเป็น `business-marketing` โดยคงคำตอบอื่น | แสดงข้อความไม่พบคอร์สและข้อจำกัดจาก API เช่นหมวดหมู่ไม่ตรง 6 คอร์ส; ไม่มีการผ่อนเงื่อนไขอัตโนมัติ |
| แก้คำตอบ | กด “แก้คำตอบ” จากหน้าผลลัพธ์ | กลับข้อแรกและคงระดับ ภาษา งบ และเวลาเดิมไว้ |
| ตรวจคำตอบไม่ครบ | กดถัดไปโดยยังไม่เลือกระดับและภาษา | อยู่ข้อเดิมและแสดงข้อความให้เลือกข้อมูลก่อน |

การลองผ่าน browser นี้เป็น smoke test แบบทำด้วยมือ ยังไม่มีสคริปต์ browser E2E ที่รันอัตโนมัติใน CI
